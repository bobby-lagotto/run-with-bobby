Policy

Privacy

Last updated: 15 September 2026. Controller: Francesco Saverio Mazzi — francemazzi@gmail.com. Versione italiana.

Run with Bobby is a running coach for iPhone. The default path is local: chat, runner profile, training plans, and nutrition plans stay on the device. The app does not run advertising tracking and does not sell data.

On-device data

DataWhere it livesNetwork
ConversationsApp Documents, protectedOnly if you enable a cloud provider
Runner profileApp Documents, protectedOnly if you enable a cloud provider
Training and nutrition plansApp Documents, protectedOnly if you enable a cloud provider
API keys (OpenAI, Anthropic, OpenRouter)iOS KeychainOnly as authorization to the provider you chose
MLX modelsLocal cacheModel file download; not personal data

You can delete chat, profile, and plans in the app (“Delete local data”). API keys are removed from AI Settings.

Apple Health (HealthKit)

With your permission, Run with Bobby can read health and workout metrics (for example heart rate, HRV, sleep, steps, workouts) to personalize recovery briefings and match your runs. These summaries are not stored by the app: they are read on demand from Apple Health.

The app can write a workout to Health only if you record a run session. You can revoke access in iOS Settings → Health.

In Local mode, HealthKit data does not leave the phone. If you select a cloud provider, a Health summary needed for the reply may be sent to that provider, after in-app confirmation when required.

Location

Location is used only during a run session, for distance and route, and stays on the device. It is not used for advertising.

Optional cloud providers

OpenAI, Anthropic, and OpenRouter are not the default. They work only if you paste your own API key. In that case the provider receives the context needed to generate a reply (recent chat, profile, plan, and, if required, a Health summary). Those services have their own privacy policies. The app does not use Claude.ai or ChatGPT consumer logins.

Local mode never falls back to the cloud. Automatic mode uses the local model when it is available.

What we do not do

  • No advertising tracking, no advertising identifier, no third-party analytics.
  • No required account, no paywall, no StoreKit.
  • No sale of data to brokers.

Children

The app is not intended for children under 13 and does not knowingly collect data from children.

Rights and contact

You control local data: view it, edit your profile and plans, and delete it in the app. Questions: francemazzi@gmail.com or GitHub Issues.
