On-device coach

The coach lives on your iPhone.

Bobby is a local running AI agent: plans, recovery, and the Today tab, even offline. Cloud only if you choose it.

App Store Privacy policy

No subscription. No data leak by default.

Same world as the park full of dogs in the README: a pack that runs, and a coach that stays in your pocket.

On-device After you download the model, Bobby talks, plans, and answers on the phone. No network wait for the local coach.
Privacy by default Chat, profile, and plans stay on the device in Local mode. Cloud providers start only with an API key you paste in.
Today, not a PDF Today’s session, recovery briefing, weekly adherence, and a widget. Then log the run if you want.
Free No paywall, no StoreKit. HealthKit is read-only unless you record a session, which can write a workout to Health.

What you see in the app

App Store listing screenshots: Wimmelbild artwork and the real UI.

Requirements and support

iPhone, iOS 17+ The local model needs storage and RAM. At least 3 GB free is recommended. MLX does not run in the Simulator.
